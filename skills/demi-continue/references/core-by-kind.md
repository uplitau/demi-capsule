# Core by Kind

The Registry forms the Conceptual Core at registration, shaped by the work's Kind. The outline below helps the person check their file before registering, and helps decide the next step after.

| Kind | For | Core shape (draft outline) | Typical next steps (Continue) |
|---|---|---|---|
| TECH | Code, systems, specifications, instructions | Core statement; numbered claims (T1, T2…) on what it does; constraints; how each claim is tested; boundaries and OPEN items | Test a claim; fix an OPEN item; build the next version |
| SCI | Research, analysis, theory, data | Core statement; hypotheses (H1, H2…) each with a falsification condition; method; limits | Design a test of one hypothesis; review evidence; write up a finding |
| STM | Statements, policies, positions, declarations | Core statement; numbered statements (S1, S2…); scope; what would make each statement untrue | Check a statement against evidence; prepare a companion or public page |
| NOV | Fiction, creative and narrative work | Premise; characters and world; structure; themes; what is original | Develop a chapter or scene; adapt; translate |
| AGR | Agreements, terms, arrangements | Parties' roles (no personal data); obligations; conditions; term; open points | Prepare questions for a lawyer; draft the next version |

Older records may use one fixed five-part Core (Core Statement, Propositions, Constraints, Mechanisms, Boundaries). Read both shapes.
